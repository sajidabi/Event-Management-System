# Event-Management-System

## Online Event Planning and Management Platform

This project is a web-based Event Management System developed using Laravel.

### User Roles

1. **Admin:** Manages users, vendors, categories, services, and bookings.
2. **Vendor:** Creates a profile, adds services and packages, and accepts or rejects booking requests.
3. **Customer:** Searches for services, compares prices, and books services online.

### Technologies Used

- Laravel
- PHP
- MySQL
- HTML
- CSS
- JavaScript
- Bootstrap
